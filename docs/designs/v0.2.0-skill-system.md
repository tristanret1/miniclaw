# Design: Skill System (v0.2.0)

> Iteration: v0.2.0
> Date: 2026-03-11
> Status: Implemented

## Goal

为 miniclaw 引入 skill 系统，兼容 Clawhub 上的 SKILL.md 格式，让 bot 可以加载、发现、执行 skill。

## Background

openclaw 的 skill 系统核心设计：
- Skill 是一个**目录**，包含 `SKILL.md`（YAML frontmatter + Markdown 指令）
- Skill 本质是**指令文档**，教 agent 如何使用工具完成任务，而非代码
- Skill 被注入到 system prompt 中，agent 根据 skill 内容决定调用哪些工具
- 支持 user-invocable（用户通过 `/command` 触发）和 model-invocable（agent 自动判断使用）

## SKILL.md 格式（Clawhub 兼容）

```markdown
---
name: skill-name
description: "What this skill does. Use when: ... NOT for: ..."
metadata: { "openclaw": { "emoji": "🐙", "requires": { "bins": ["gh"] } } }
user-invocable: true
---

# Skill Instructions

Markdown content teaching the agent how to perform the task...
```

### Frontmatter 字段

| Field | Required | Description |
|-------|----------|-------------|
| `name` | Yes | Skill 唯一标识（kebab-case） |
| `description` | Yes | 单行描述，包含使用场景和排除场景 |
| `metadata` | No | openclaw 兼容的元数据（emoji, requires, install） |
| `user-invocable` | No | 是否可通过 `/command` 触发（默认 true） |
| `disable-model-invocation` | No | 是否排除出 system prompt（默认 false） |

## Module Design: `bot/skills.py`

### 1. Skill 数据结构

```python
@dataclass
class Skill:
    name: str
    description: str
    body: str                           # Markdown 指令内容
    user_invocable: bool = True
    model_invocable: bool = True        # not disable-model-invocation
    emoji: str = ""
    requires_bins: list[str] = field(default_factory=list)
```

### 2. Skill 加载

```python
def load_skills(skills_dir: Path) -> list[Skill]:
    """扫描 skills_dir 下所有子目录，解析 SKILL.md"""
```

- 扫描 `skills/*/SKILL.md`
- 解析 YAML frontmatter + Markdown body
- 检查 `requires.bins` 是否满足（`shutil.which`）
- 跳过不满足依赖的 skill，log warning

### 3. Prompt 注入

```python
def build_skills_prompt(skills: list[Skill]) -> str:
    """将所有 model-invocable 的 skill 格式化为 system prompt 片段"""
```

格式：
```
<available-skills>
<skill name="github" description="GitHub operations via gh CLI">
[SKILL.md body content]
</skill>
<skill name="weather" description="Get weather via wttr.in">
[SKILL.md body content]
</skill>
</available-skills>
```

注入到 system prompt 末尾，让 agent 知道有哪些能力可用。

### 4. Slash Command 分发

```python
def match_skill_command(text: str, skills: list[Skill]) -> tuple[Skill, str] | None:
    """检查消息是否以 /skill-name 开头，返回 (skill, args)"""
```

- 用户发送 `/github list my PRs` → 匹配到 `github` skill
- 将 skill body + 用户参数组合成 user message 发给 Claude
- 格式：`[Skill: {name}] {skill.body}\n\nUser request: {args}`

## Integration Points

### config.py
```python
SKILLS_DIR = Path(__file__).parent.parent / "skills"
```

### config.py — build_system_prompt()
- 加载所有 skills
- 将 model-invocable skills 注入 system prompt

### client.py — on_message()
- 检查消息是否以 `/` 开头
- 如果匹配到 skill，将 skill context 注入 user message
- 不匹配则正常处理

## Scope（v0.2.0 不做的）

- ❌ Clawhub install/publish CLI
- ❌ Skill 热重载（file watching）
- ❌ Skill config 系统（per-skill env/apiKey）
- ❌ references/ 子目录加载
- ❌ install 自动安装依赖
- ❌ 多 skill 源（只支持本地 `skills/` 目录）

这些留给后续迭代。
