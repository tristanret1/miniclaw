🌗 日夜循环

时间映射

  • 同步真实时间 — 小镇时间 = 本地系统时间
  • 6:00-8:00 日出渐变（暖橙色滤镜渐退）
  • 8:00-17:00 白天（正常亮度）
  • 17:00-19:00 日落渐变（暖金色→暗紫色）
  • 19:00-6:00 夜晚（深蓝色滤镜 + 星星）

视觉效果

  • PixiJS ColorMatrixFilter 实现全局色调
  • 夜间：小屋窗户亮灯（agent 在线时）、路灯亮起
  • 日出/日落：天空渐变色带 + 影子方向变化
  • 星空：随机闪烁的小白点叠加层

🎮 交互面板

地图上的交互

  • 点击 agent → 弹出状态气泡（名字、状态、简要信息）
  • 双击 agent → 打开消息输入框，直接发消息
  • 点击小屋 → 进入室内视图（详细状态 + 操作）
  • 点击告示牌 → 显示全局状态仪表盘
  • 拖拽建筑 → 自定义小镇布局（编辑模式）

侧边操作栏

  • Agent 列表 — 快速查看所有 agent 状态
  • 消息日志 — 最近的 agent 活动流
  • Cron 任务 — 查看/触发计划任务
  • 设置齿轮 — 天气模式、布局编辑、音效开关
  • 时钟 — 当前时间 + 季节指示
