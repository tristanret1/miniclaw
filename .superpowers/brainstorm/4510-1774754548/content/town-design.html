场景区域

🏠 Agent 小屋（每人一间）

  • 外观根据 IDENTITY.md 的 emoji/性格差异化（颜色、装饰）
  • 小屋门口有信箱 — 显示未读消息数
  • 点击小屋进入内部视图（家具、状态详情）
  • 屋顶烟囱：工作中冒烟 💨，空闲时不冒

⛲ 中央广场

  • 公共社交区 — agent 闲逛时来这里
  • 告示牌：显示全局状态摘要（活跃 agent 数、今日任务数）
  • 长椅：两个 agent "聊天"时坐在一起
  • 喷泉：纯装饰 + 水流动画

📚 图书馆

  • agent 工作时的去处（坐在桌前看书/打字动画）
  • 代表"正在处理任务"的视觉隐喻
  • 窗户透出灯光 — 有 agent 在工作时亮灯

🏪 商店（预留）

  • 为未来功能预留的建筑位置
  • 可用于：技能商店、工具升级、agent 定制
  • V1 先作为装饰建筑存在

数据驱动社交

亲密度系统：

  • 数据来源：sessions.db 中两个 agent 被同一用户在相近时间内提到的频率
  • 影响行为：亲密度高的 agent 更频繁串门、在广场碰面时聊天时间更长
  • 视觉表现：社交时对话气泡颜色更暖（从白→粉→红），表示关系亲密
  • 衰减机制：长时间没有共同交互 → 亲密度自然下降
