核心设计决策

🏗 新增模块

  • bot/gateway/pixeltown.py — WebSocket gateway + static file server
  • bot/status.py — Agent 状态追踪器，聚合各来源事件
  • pixeltown/ — 前端项目目录（PixiJS + Vite）

🔌 集成方式

  • 和 SMS gateway 同模式：在 main.py 中作为额外 async task 启动
  • config.yaml 新增 gateway.pixeltown 配置段
  • 复用现有 SessionManager、CronScheduler 的数据
