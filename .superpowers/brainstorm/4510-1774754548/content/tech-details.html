🐍 后端新增模块

bot/gateway/pixeltown.py

职责：
• aiohttp web server（端口可配置，默认 8765）
• 静态文件服务：pixeltown/dist/
• WebSocket 端点：/ws
• REST API 端点：
  GET  /api/agents        → agent 列表 + 当前状态
  GET  /api/agents/:id    → 单个 agent 详情
  GET  /api/cron           → cron job 列表
  POST /api/agents/:id/message → 发送消息
  POST /api/agents/:id/trigger → 触发任务
  PUT  /api/town/layout    → 保存布局
  GET  /api/weather        → 当前天气

bot/status.py

职责：
• AgentStatusTracker 类
• 监听事件源：
  - client.py: on_message → agent 开始/结束处理
  - cron.py: job_started / job_finished
  - gateway/*: 各 gateway 的活动事件
• 聚合状态：working / idle / sleeping / offline
• 计算社交亲密度：
  - 查询 sessions.db 中 agent 交互重叠
  - 维护 affinity_scores: dict[tuple, float]
• 广播状态变化 → pixeltown gateway 推送

🎨 素材方案

推荐素材包（itch.io CC0/free）：

  • 角色：16×16 或 32×32 像素人物 sprite sheet（4方向行走、坐下、睡觉动画）
  • 建筑/地图：星露谷风格的 tileset（房屋、路径、树木、花草、水体）
  • 季节变体：同一 tileset 的 4 季配色变体
  • UI：像素风格的按钮、面板、图标、对话框
  • 天气粒子：雨滴、雪花、闪电的小型 sprite

V1 先用免费素材快速搭建，后续可按 agent 个性替换定制素材。角色通过颜色 tint 区分不同 agent。

⚙️ 配置（config.yaml 新增）

gateway:
  pixeltown:
    enabled: true
    port: 8765
    host: "127.0.0.1"
    static_dir: "pixeltown/dist"    # Vite 构建输出
    weather_mode: "simulated"        # "simulated" | "real"
    weather_api_key: ""              # OpenWeatherMap (optional)
    layout_file: "workspace/town_layout.json"
    idle_behavior:
      wander_interval: [10, 30]      # 闲逛间隔 (秒)
      social_chance: 0.3             # 碰面时触发社交的概率
      sleep_after: "23:00"           # 超过此时间 → sleeping 状态
